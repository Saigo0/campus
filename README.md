# CampUs Frontend

This is the frontend application for **CampUs**, a platform for advertising rental properties for university students.

## Requirements

Before running this project, make sure you have installed:

- Node.js (v18 or later)
- npm

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USER/Campus.git
cd Campus
```

### 2. Start the backend

This project depends on the CampUs backend. Clone and start it first:

https://github.com/PedroWiggersDev/CampusBackend

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The application will be available at:

http://localhost:3000

## Technologies

- Next.js
- React
- Tailwind CSS
- Axios
